# Baldoni et al. 2025 — Table 2

“Programmed seasonal brain shrinkage in the common shrew via water loss without cell death,” *Current Biology*, DOI 10.1016/j.cub.2025.08.015. The exact main article PDF is in this folder; Table 2 is on PDF page 4 (printed p. 4). The frozen snapshot was manually checked against the rendered table on 2026-11-24 and retains its seven metric names, estimates, estimated errors, and credible intervals. Negative effects indicate a decrease from summer to winter, positive effects an increase. These are model estimates, not raw diffusion or tissue water values.

Run from repository root: `Rscript --vanilla Baldoni_etal_2025/Baldoni_etal_2025_Table2.R`. The reader uses only the frozen snapshot and writes analysis CSV and DOI-coded public TSV via `__ReadMeAddON.xlsx`. It checks that every printed estimate lies within its printed interval. Human visual signoff remains pending. No figure-derived data were extracted.
