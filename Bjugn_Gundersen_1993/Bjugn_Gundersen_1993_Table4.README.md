# Bjugn and Gundersen 1993 — Table 4

Same exact paper and DOI as Table 1. Printed Table 4 is on PDF page 5 (printed p. 410). The two source rows compare Giemsa and Mayer’s haematoxylin staining in **the same rat, animal 2**; cell numbers are in millions. The manual frozen snapshot retains the printed stain labels and all four count columns. The analysis reader checks, separately for each stain, that glia + endothelium + neurons equals the printed all-cell total (24.3 and 24.2 million). These are alternative estimates for one animal, not independent specimens; they should not both enter a species-level mean with Table 2.

Run from repository root: `Rscript --vanilla Bjugn_Gundersen_1993/Bjugn_Gundersen_1993_Table4.R`. The reader uses only the snapshot and writes two analysis rows plus the DOI-coded public TSV via `__ReadMeAddON.xlsx`. Codex checked the source page on 2026-11-24; human visual signoff remains pending. No figure-derived data were extracted.
