# Bjugn Gundersen 1993 — Table5

Bjugn, R., & Gundersen, H. J. G. (1993). Estimate of the total number of neurons and glial and endothelial cells in the rat spinal cord by means of the optical disector. *Journal of Comparative Neurology*, 328, 406–414. [DOI](https://doi.org/10.1002/cne.903280307).

## Source and scope

The exact source PDF is held as `Bjugn-1993-Estimate of the total number of neu.pdf` in this folder. This item is Table 5 on PDF page 5 (printed page 410). The frozen CSV snapshot was made by manual transcription from the scanned printed table; OCR was used only to locate cells, in source row and column order, and checked against a rendered page by Codex on 2026-11-24. Four regional means across five rats for gray-matter volume and glial, endothelial and neuron numbers. White-matter regional cell counts are not printed in this table. Regional rounded counts need not sum exactly to the more precise whole-cord means in Table 2.

## Build and validation

From repository root run `Rscript --vanilla Bjugn_Gundersen_1993/Bjugn_Gundersen_1993_Table5.R`. The reader uses only this item’s frozen snapshot and writes its analysis CSV and the public TSV named by the `__ReadMeAddON.xlsx` registry row. 12 long rows (4 regions × 3 cell classes), with region volume repeated for joins. Numeric cells remain as printed; no figures were extracted in this item, so no figure replot applies. The source PDF and snapshot still need human visual signoff before downstream merge.
