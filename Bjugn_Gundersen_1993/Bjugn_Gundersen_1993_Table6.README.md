# Bjugn Gundersen 1993 — Table6

Bjugn, R., & Gundersen, H. J. G. (1993). Estimate of the total number of neurons and glial and endothelial cells in the rat spinal cord by means of the optical disector. *Journal of Comparative Neurology*, 328, 406–414. [DOI](https://doi.org/10.1002/cne.903280307).

## Source and scope

The exact source PDF is held as `Bjugn-1993-Estimate of the total number of neu.pdf` in this folder. This item is Table 6 on PDF page 6 (printed page 411). The frozen CSV snapshot was made by manual transcription from the scanned printed table; OCR was used only to locate cells, in source row and column order, and checked against a rendered page by Codex on 2026-11-24. One rat (animal 1), gray matter only, and only cord down to mid-lumbar segments. Ventral horns, middle portion and dorsal horns each have volume and cell counts. Category 1/2 values are percentages of neurons with the morphological criteria in footnotes, not extra cells. Each region’s percentages sum to 100.

## Build and validation

From repository root run `Rscript --vanilla Bjugn_Gundersen_1993/Bjugn_Gundersen_1993_Table6.R`. The reader uses only this item’s frozen snapshot and writes its analysis CSV and the public TSV named by the `__ReadMeAddON.xlsx` registry row. 3 compartment rows with volume, three cell counts and category percentages. Numeric cells remain as printed; no figures were extracted in this item, so no figure replot applies. The source PDF and snapshot still need human visual signoff before downstream merge.
