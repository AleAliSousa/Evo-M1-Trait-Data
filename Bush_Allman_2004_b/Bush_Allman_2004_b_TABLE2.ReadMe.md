### Source -> Snapshot

PDF p. 6 (journal p. 1093). `Bush_Allman_2004_b_TABLE2_snapshot.csv` is a frozen transcription of the published table: 3 species rows. Counts are stored without thousands separators; species and reference wording are retained as printed, with obvious OCR typography repaired.

### Data readable

`Bush_Allman_2004_b_TABLE2.R` reads the frozen snapshot and writes `Bush_Allman_2004_b_TABLE2.csv` plus the DOI/PMID-coded public TSV named from `__ReadMe.xlsx`. The build preserves published species names; project-key harmonisation belongs downstream.
