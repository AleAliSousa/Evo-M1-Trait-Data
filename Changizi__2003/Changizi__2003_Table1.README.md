# Changizi 2003 — Table 1 (ethogram sizes, encephalization, muscle-type counts)

Changizi MA (2003). *Relationship between number of muscles, behavioral repertoire size, and
encephalization in mammals.* J Theor Biol 220:157–168. doi:10.1006/jtbi.2003.3125.

Registry: **`Changizi__2003_Table1`**, encoded `10.1006%2Fjtbi.2003.3125_Table1`; stage blank →
set after R rerun. Registry note: "directly provides comparative species/order behavioral
repertoire values."

## What the data are
35 rows across 12 mammalian orders: **order rows** (order-mean ethobehavior count,
encephalization index, muscle-type count + anatomy citation) and **23 species rows** (published
ethogram size + primary citation, species encephalization index per Changizi 2001b).
Names as printed, kept verbatim: *Blarina brevicaudo* [=brevicauda], *Calithrix jacchus*
[=Callithrix], truncated *Meriones unguicul.* / *Peromyscus manicul.* / *Dolichotis patagon*,
supra-specific "Leporidae (family)" / "Sciuridae (four species)"; order "Insectivora" is
historical. **SECONDARY-leaning**: behavior and muscle counts are compiled from the per-row
primary citations (retained in the data).
