# Charvet et al. 2017 — Table 1

Charvet et al., “Combining Diffusion Magnetic Resonance Tractography With Stereology Highlights Increased Cross-Cortical Integration in Primates,” *Journal of Comparative Neurology* 525:1075–1093. DOI: 10.1002/cne.24115. Exact PDF: `Charvet-2017-Combining diffusion magnetic reso.pdf`, PDF page 3 (printed p. 1077).

The frozen snapshot retains all 25 printed species rows, source common/scientific names, two layer columns, source order and original values in millions. Its script extracts the page's selectable text and refuses to overwrite a differing snapshot. The item reader converts counts to absolute unilateral neurons, preserving the printed species labels. Table 1 includes new data and six previously published species sets (Charvet et al. 2015/2016); the table itself does not identify source on each row. Figure 1 and the earlier papers must be reconciled before these rows are merged as primary. Its *Felis silvestris* is a phylogeny substitution for sampled domestic cats (*F. catus*); the source label remains intact. No group is silently pooled or reidentified.

From the repository root run `Rscript --vanilla Charvet_etal_2017/Charvet_etal_2017_Table1_snapshot.R` then `Rscript --vanilla Charvet_etal_2017/Charvet_etal_2017_Table1.R`. The reader uses only its frozen snapshot and writes 25 analysis CSV rows and the DOI-coded public TSV via `__ReadMeAddON.xlsx`. I checked the captured row order and values against the rendered source table on 2026-11-24; human snapshot signoff remains pending. No figure-derived data were extracted.
