# Cordain et al. 2000 Table 2

Source: `Cordain-2000-Plant-animal subsistence ratios a.pdf`, Mean economic subsistence dependence in worldwide hunter-gatherer societies (n = 63) by primary living environment,
printed p. 686 (PDF p. 5). The manual snapshot preserves the printed
row order and all source cells. Run `Rscript Cordain_etal_2000/Cordain_etal_2000_Table2.R`
from the repo root to rebuild the analysis CSV. The PDF page and snapshot
were compared on 2026-11-26; no human visual signoff is claimed.

The ten environment groups include 63 societies in total. Each food-source
entry is a percentage **class interval**, not an exact observed percentage
or a midpoint. Lower and upper endpoints are parsed separately; the printed
range is also retained. This is a secondary summary of ethnographic data,
not 63 individual society records.
