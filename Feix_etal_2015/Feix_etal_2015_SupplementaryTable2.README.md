# Feix et al. 2015, Supplementary Table 2

Feix, T., Kivell, T. L., Pouydebat, E., & Dollar, A. M. (2015). Estimating thumb–index finger precision grip and manipulation potential in extant and fossil primates. *Journal of the Royal Society Interface*, 12, 20150176. [DOI](https://doi.org/10.1098/rsif.2015.0176).

## Source and scope

The open [author PDF](https://www.eng.yale.edu/grablab/pubs/Feix_Interface2015.pdf) is frozen here as `Feix-2015-Estimating-thumb-index-precision-grip.pdf`; the appended Supplementary Table 2 prints raw segment lengths in mm. The snapshot contains all 144 printed rows and seven bone segment columns, in source order. The fossil *Au. afarensis* composite key spans lines in the PDF; its printed text was joined into each snapshot Key cell. Blank Group cells reflect the table's block formatting. The source label `Alouatta semiculus` is retained and keyed to *Alouatta seniculus* as an apparent spelling error. Historical *Presbytis cristata* maps to *Trachypithecus cristatus*. Historical *Pongo pygmaeus* remains `Pongo sp.` pending specimen-level identification.

The `Au. afarensis comp H/P` and `Au. sediba MH2 H/P` rows reflect alternative model configurations, not independent individuals. Their variant labels and original species strings remain in the CSV. These raw lengths are one upstream input to the paper's modeled workspace; Supplementary Table 1 modeled outputs are now built as a separate item. Avoid pooling this source with secondary Liu 2016 or Baker 2025 workspace values.

`Feix_etal_2015_SupplementaryTable2_snapshot.R` captures the three-page PDF text table, joins the two line-wrapped composite keys, and writes only the frozen snapshot. From repository root, run `Rscript --vanilla Feix_etal_2015/Feix_etal_2015_SupplementaryTable2_snapshot.R` to reproduce it. `Feix_etal_2015_SupplementaryTable2.R` reads only that snapshot and writes 144 analysis rows and a DOI-coded public TSV. It checks that all seven measurements are numeric and positive. No printed totals are available for an independent arithmetic check. Run from repository root: `Rscript --vanilla Feix_etal_2015/Feix_etal_2015_SupplementaryTable2.R`. No figure-derived data are in this item, so no replot applies.
