# Feix et al. 2015 — Table 1

“Estimating thumb–index finger precision grip and manipulation potential in extant and fossil primates,” *Journal of the Royal Society Interface* 12:20150176, DOI 10.1098/rsif.2015.0176. The exact PDF is in this folder; main-text Table 1 is on PDF page 6. `Feix_etal_2015_Table1_snapshot.R` froze the 28 printed rows in source order from the local PDF text layer on 2026-11-24. The snapshot preserves the three printed group headings, taxon strings, workspace, relative object size, and real object size in mm. The text extraction was visually checked against the rendered page for the discordant Hylobates cell.

Run from repository root: `Rscript --vanilla Feix_etal_2015/Feix_etal_2015_Table1.R`. The reader uses only the frozen snapshot and writes analysis CSV and DOI-coded public TSV via `__ReadMeAddON.xlsx`. Main Table 1 is a 28-row subset of the 45-row Supplementary Table 1; **do not count both as independent observations**. The main table prints *Hylobates lar* real object size as **2.20 mm**, while the supplement prints **22.2 mm**. Both source values are retained in their own items and the discrepancy needs source or author clarification before using that cell. Fossil `human` and `Pan` variants are model assumptions, not separate specimens. Human visual signoff remains pending. No figure-derived data were extracted.
