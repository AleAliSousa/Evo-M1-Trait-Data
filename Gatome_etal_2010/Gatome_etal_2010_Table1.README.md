# Gatome etal 2010 — Table1

Gatome, C. W., Slomianka, L., Lipp, H. P., & Amrein, I. (2010). Number estimates of neuronal phenotypes in layer II of the medial entorhinal cortex of rat and mouse. *Neuroscience*, 170, 156–165. [DOI](https://doi.org/10.1016/j.neuroscience.2010.06.048).

## Source and scope

The exact source PDF is held as `Gatome-2010-Number estimates of neuronal pheno.pdf` in this folder. This item is Table 1 on PDF page 5 (printed page 160). The frozen CSV snapshot was made by manual transcription from the printed table with text-layer cross-check, in source row and column order, and checked against a rendered page by Codex on 2026-11-24. Eleven individual animals (five rats and six mice), plus one mean row per species. Unilateral neuron counts for CE, ME and MEA were rounded to the next 100; the group SD is printed in parentheses only on Mean rows. CE is coefficient of error, not standard error. The source MEA count exceeds printed CE+ME by 100 in rat 2 and mouse 3, and by 600 in mouse 6; all numbers remain as printed. The individual sections came from prior rat and mouse studies, so specimen overlap needs review.

## Build and validation

From repository root run `Rscript --vanilla Gatome_etal_2010/Gatome_etal_2010_Table1.R`. The reader uses only this item’s frozen snapshot and writes its analysis CSV and the public TSV named by the `__ReadMeAddON.xlsx` registry row. 39 long rows (13 printed rows × 3 fields), individual versus group summary flagged. Numeric cells remain as printed; no figures were extracted in this item, so no figure replot applies. The source PDF and snapshot still need human visual signoff before downstream merge.
