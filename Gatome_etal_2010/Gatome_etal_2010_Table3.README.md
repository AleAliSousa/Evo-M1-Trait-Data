# Gatome etal 2010 — Table3

Gatome, C. W., Slomianka, L., Lipp, H. P., & Amrein, I. (2010). Number estimates of neuronal phenotypes in layer II of the medial entorhinal cortex of rat and mouse. *Neuroscience*, 170, 156–165. [DOI](https://doi.org/10.1016/j.neuroscience.2010.06.048).

## Source and scope

The exact source PDF is held as `Gatome-2010-Number estimates of neuronal pheno.pdf` in this folder. This item is Table 3 on PDF page 6 (printed page 161). The frozen CSV snapshot was made by manual transcription from the printed table with text-layer cross-check, in source row and column order, and checked against a rendered page by Codex on 2026-11-24. Six phenotype/field rows for the three common cell types in CE and ME. Dorsal and ventral density, sectional area, SD and printed P values are retained by species. The paper defines density here as cells counted per disector, not cells per mm³; no volume-density unit is invented. Sectional area is in μm², not soma volume.

## Build and validation

From repository root run `Rscript --vanilla Gatome_etal_2010/Gatome_etal_2010_Table3.R`. The reader uses only this item’s frozen snapshot and writes its analysis CSV and the public TSV named by the `__ReadMeAddON.xlsx` registry row. 48 long rows (6 printed rows × 2 species × 2 measures × 2 dorsoventral positions). Numeric cells remain as printed; no figures were extracted in this item, so no figure replot applies. The source PDF and snapshot still need human visual signoff before downstream merge.
