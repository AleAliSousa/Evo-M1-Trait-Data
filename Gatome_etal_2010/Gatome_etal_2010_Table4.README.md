# Gatome etal 2010 — Table4

Gatome, C. W., Slomianka, L., Lipp, H. P., & Amrein, I. (2010). Number estimates of neuronal phenotypes in layer II of the medial entorhinal cortex of rat and mouse. *Neuroscience*, 170, 156–165. [DOI](https://doi.org/10.1016/j.neuroscience.2010.06.048).

## Source and scope

The exact source PDF is held as `Gatome-2010-Number estimates of neuronal pheno.pdf` in this folder. This item is Table 4 on PDF page 6 (printed page 161). The frozen CSV snapshot was made by manual transcription from the printed table with text-layer cross-check, and checked against a rendered page by Codex on 2026-11-24. On 2026-11-27 its printed caption, grouped header rows, and source section rows were restored; the R reader now selects data rows and supplies analysis field labels. Three common phenotype rows, collated for MEA layer II in rat and mouse. Density is cells per disector by the Methods, sectional area in μm², and proportion in percent. Means and SDs are preserved; the three listed phenotype proportions do not sum to 100 because other phenotypes are omitted from this table.

## Build and validation

From repository root run `Rscript --vanilla Gatome_etal_2010/Gatome_etal_2010_Table4.R`. The reader uses only this item’s frozen snapshot and writes its analysis CSV and the public TSV named by the `__ReadMe.xlsx` registry row. 18 long rows (3 phenotypes × 2 species × 3 measures). Numeric cells remain as printed; no figures were extracted in this item, so no figure replot applies. The source PDF and snapshot still need the independent human source comparison.
