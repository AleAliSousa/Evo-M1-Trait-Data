# Glezer et al. 1993 — Table 2

“Calcium-binding protein-containing neuronal populations in mammalian visual cortex: A comparative study in whales, insectivores, bats, rodents, and primates,” *Cerebral Cortex* 3:249–272, DOI 10.1093/cercor/3.3.249. Exact scanned PDF in this folder. Table 2 starts on PDF page 8 and continues on page 9. The frozen source-order snapshot was manually transcribed from 300 dpi rendered pages on 2026-11-24. It retains all 5 taxonomic columns × 11 layer rows, including printed dashes. The table reports calbindin-positive cell numerical density per mm³ as mean ± SEM, plus percent of total neurons. `AVG` is a printed cortex average within each mammalian order, not an extra layer or species.

Run from repository root: `Rscript --vanilla Glezer_etal_1993/Glezer_etal_1993_Table2.R`. The reader uses only the frozen snapshot and writes an analysis CSV and DOI-coded public TSV via `__ReadMeAddON.xlsx`. Dashes mean either no immunoreactive cells or a layer/sublayer not represented, per the printed footnote; the source does not distinguish which, so analysis values are missing rather than zero. Cetacean `IIIc/V` is a specially designated layer because layer IV is absent; rodents, bats, and hedgehogs have an unsublaminated IV. The five taxonomic groups are pooled order-level summaries; do not use their rows as species observations. The printed mean and percent values are preserved without recomputing the average or pooling across layers. Human visual signoff remains pending. No figure-derived data were extracted.
