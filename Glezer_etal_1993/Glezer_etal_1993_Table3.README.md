# Glezer et al. 1993 — Table 3

“Calcium-binding protein-containing neuronal populations in mammalian visual cortex: A comparative study in whales, insectivores, bats, rodents, and primates,” *Cerebral Cortex* 3:249–272, DOI 10.1093/cercor/3.3.249. Exact scanned PDF in this folder; Table 3 is on PDF page 12. The frozen source-order snapshot was manually transcribed from the 300 dpi rendered page on 2026-11-24. It contains five cortical layers and the printed AVG row, each averaged across five species of toothed whales. GABA and parvalbumin-plus-calbindin percentages are printed as mean ± SD. No species-specific counts or measurements are given in this table.

Run from repository root: `Rscript --vanilla Glezer_etal_1993/Glezer_etal_1993_Table3.R`. The reader uses only the frozen snapshot and writes an analysis CSV and DOI-coded public TSV via `__ReadMeAddON.xlsx`. It retains the printed difference column and provides a separate recomputed difference for audit. The layer VI source difference is −2.3 percentage points, although the displayed component means imply −2.8. The AVG source difference is +3.2, while the displayed means imply +3.1. Neither source number is overwritten or used to infer a corrected measurement. These are order-level pooled summaries, unsuitable for species-level merging. Human visual signoff remains pending. No figure-derived data were extracted.
