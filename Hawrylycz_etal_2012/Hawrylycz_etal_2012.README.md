## What the owner called "Allen Inst bulk RNA"
Hawrylycz et al. 2012 is the initial publication of the adult AHBA microarray atlas; the paper analyzed the first **two** adult donor brains. The current Allen download provides normalized microarray data for **six** adult donor brains, including four released later. The six-donor processed matrix below therefore cites Hawrylycz as the atlas's founding publication but is not an exact two-donor table from that article. This is microarray, not RNA-seq. (Allen also released RNA-seq for selected samples from two of the six brains.) Castrillon et al. 2023 (dataset #4) used the microarray via the abagen pipeline as packaged in the ENIGMA toolbox (HCP-MMP1.0 parcels, 8,426 genes after donor-consistency filtering ≥ 0.2).

## Route A — ENIGMA toolbox precomputed matrices (fast; fixed parcellations)
`enigmatoolbox.datasets.fetch_ahba()` returns parcel × gene matrices (abagen defaults; parcellations: Desikan-Killiany 68, Schaefer 100–400, Glasser 360 (HCP-MMP1.0)). Files are downloaded by the function from the ENIGMA GitHub repository (raw.githubusercontent.com) — host must be allow-listed. `pip install enigmatoolbox` pulls VTK (hundreds of MB; the sub-agent's install hung for >90 min in the sandbox) — install from a wheel or only download the CSVs directly from the repository instead. Joins: Glasser 360 ↔ Wagstyl S1 (same HCP-MMP parcels); DK 68 ↔ Hansen 2022 scale033 (83 regions, DK-based) after a DK-scale check.

## Route B — abagen with Julich-Brain v3.1 (preferred for this project; slow)
`abagen.get_expression_data(atlas=JulichBrain_v31_MNI152_labelled_merged.nii.gz, atlas_info=<from the lut>)` with default settings (probe selection by differential stability, scaled-robust-sigmoid normalisation, mirrored samples, donor averaging). Needs the raw AHBA download (~4 GB; hosts human.brain-map.org / api.brain-map.org, allow-list required) and ~20–40 min compute. Output: 300-region × ~15,000-gene matrix joining c0 directly. Record abagen version and the full parameter set in `abagen_julich_v31/parameters.json`.

## Why this source entered the project — citation check 2026-11-26

**Castrillon et al. 2023 is the direct lead.** Its Methods dataset 4 cites Hawrylycz et al. 2012 (reference 84), then uses a preprocessed AHBA bulk microarray matrix from ENIGMA/abagen on HCP-MMP1.0 Glasser parcels. It correlates gene profiles with parcel-level energetic costs (Figure 4), reporting 617 significant expression profiles. The exact author-code input is already retained at `_SOURCE_DISPOSITION/Castrillon_etal_2023/github_energetic_costs/data/external/AHBA/allgenes_stable_r0.2_glasser_360.csv` (374 rows including noncortical rows, 8,425 gene columns plus a label column). That is a **different parcellation and gene filter** from our separately processed Julich v3.1 matrix (414 regions, 15,633 genes). Do not represent the Julich matrix as Castrillon's exact input or as independently observed species traits.

**Castillo-Morales et al. 2018 is not the identified lead.** Its source Table 1 and Methods list BioGPS tissue microarrays, GEO datasets, BrainSpan developmental-cortex RNA-seq, and Brawand et al. human/macaque RNA-seq; the paper text and references do not cite Hawrylycz 2012. BrainSpan is a distinct Allen resource, not this adult AHBA microarray. The Castillo-Morales 2018 PDF is currently in the owner's EndNote library, not a paper folder here.

The justified role of Hawrylycz in this repository is upstream provenance for Castrillon's expression comparison and for the separate Julich analysis matrix. No standalone Evo-M1 species-trait item has been selected from it. The first-sheet row stays a source candidate until the intended derived analysis is specified or its consumers are checked for disposition.

## Concrete regional comparison available — 2026-11-26

Hawrylycz et al. 2012 is the primary publication of the **adult** Allen Human Brain Atlas microarray resource, not the BrainSpan developmental atlas. The Julich-parcellated AHBA matrix can be compared with the in-repository `Wei_etal_2019/derived_julich_v31/wei2019_expansion_julich_v31.csv` human/chimpanzee cortical-expansion map. An exact region-label plus hemisphere audit finds 292 left/right Wei rows in the AHBA atlas: 280 classified as cortex, of which 17 use AHBA centroid-filled expression because no sample was assigned in that hemisphere. A strict analysis would start with the other **263 cortical region/hemisphere pairs**. This is a potential spatial association between selected gene expression and expansion, not an independent measurement of expansion or validation of either dataset. Wei's Julich map is a derived analysis file; the registered published Wei item uses DK114 parcels. A research question and a specified gene set or score are needed before running an association or registering a new item. Keep the comparison in the separate regional-analysis workflow and preserve the source matrices and imputation flags.
