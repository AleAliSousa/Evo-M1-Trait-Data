# Henry et al. 2006 — source only

The PDF was copied from `Flatmap_SurfaceArea_Project/papers_to_do/cortical_flatmap_bibliography/Henry_etal_2006.pdf`.

The primary paper is “Organization of Somatosensory Cortical Areas in the Naked Mole-Rat (*Heterocephalus glaber*)” (*Journal of Comparative Neurology* 495:434–452). Its Table 1 reports receptive-field area on the skin, not cortical surface area. That table is therefore excluded from this dataset and no public TSV is created.
