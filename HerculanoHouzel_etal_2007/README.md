# Herculano-Houzel et al. 2007

Herculano-Houzel, Collins, Wong & Kaas (2007), "Cellular scaling rules for primate brains", PNAS 104(9):3562–3567. doi:10.1073/pnas.0611396104. PMC1805542.

Table 1 (whole-brain data for 7 species) was first built into this folder on 2026-10-21 from values read by eye from the publisher PDF, whose text layer is scrambled. On 2026-11-22 it was rebuilt to the project's standard — snapshot extracted programmatically from the PMC full text (the re-extraction differed from the eye-read build in zero value cells) — registered (registry row 439 in __ReadMe.xlsx), given its public TSV, and wired into the isotropic-fractionator merge: PRs #119 (build), #120 (registry), #121–#122 (wiring). See HerculanoHouzel_etal_2007_Table1.README.md for the build details, including the two naming decisions (Macaca mulatta per the Methods; the capuchin carried as Sapajus apella, printed as Cebus apella).

On 2026-11-24, the linked HTML SI Table 2 was built as `HerculanoHouzel_etal_2007_SITable2` with the three regional sections and registered in `__ReadMeAddON.xlsx`. Its item README documents two apparent published exponent errors and the specimen overlap with Table 1.

The supplementary Table 2 (structure-level data: cortex, cerebellum, rest of brain) is not built; it exists only as an online supplement.
