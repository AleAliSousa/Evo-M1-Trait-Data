# Huffman et al. 1999 — TABLE 2

Source: Huffman, K. J., Nelson, J., Clarey, J., & Krubitzer, L. (1999). Organization of somatosensory cortex in three species of marsupials, *Dasyurus hallucatus*, *Dactylopsila trivirgata*, and *Monodelphis domestica*: Neural correlates of morphological specializations. *Journal of Comparative Neurology, 403*(1), 5–32. https://doi.org/10.1002/(SICI)1096-9861(19990105)403:1<5::AID-CNE2>3.0.CO;2-F

`Huffman_etal_1999_TABLE2_snapshot.csv` preserves the printed area and percent columns for cases NQ3, NQ5, and SP1, including `*` for unreported representations. The R script emits only measured cells and uses the existing registry item `Huffman_etal_1999_TABLE2` for the DOI-coded public TSV.

The source explicitly warns that body-part rows do not add to 100% of SI because some regions overlap and some measurements are nested (for example, tongue tip within tongue). Total neocortical area is not reported.
