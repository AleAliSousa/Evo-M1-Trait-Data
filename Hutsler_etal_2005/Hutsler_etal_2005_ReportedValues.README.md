# Hutsler et al. 2005 — exact reported summaries

Forty-four numeric statements transcribed from the Results, abstract and Discussion. Printed percent
values are converted to 0–1 proportions in the clean file while the printed value/unit remain.

The table preserves conflicting supragranular order summaries under the same `conflict_group_id`.
M1 values are pooled regional or order summaries only; use their `compatibility` and `n_species`
fields to prevent accidental species-level assignment.
