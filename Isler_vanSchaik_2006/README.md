# Isler & van Schaik 2006 — brain-size methods and source evidence

Isler K, van Schaik CP (2006). *Metabolic costs of brain size evolution.* Biology Letters 2:557–560. DOI: 10.1098/rsbl.2006.0538.

The owner supplied the main PDF and `rsbl20060538supp1.pdf` on 2026-10-29. Both were copied from Desktop byte-for-byte; neither is an extracted measurement table.

Electronic Appendix A (supplement PDF p.1) lists brain/body sources for the 313-species analysis, including unpublished R.D. Martin and G.M. Mace databases. It explicitly mentions correction of a 0.59 g shift in the Mace et al. 1981 rodent data. This is evidence about a compiler correction, not permission to alter the frozen Mace table or assume the same operation for every later compilation cell.

The authors also report measuring cranial capacity with millet seeds for *Manis javanica*, *M. tricuspis* and *Orycteropus afer*, each n=1. These are direct skull-capacity method statements. No numerical capacities or specimen identifiers are supplied, so values in a later compilation cannot be assigned to these animals solely from species identity.

The remaining supplement contains phylogeny references, a Nexus tree translation and branch lengths. The 313 numbered species are tree labels, not a 313-row brain-value dataset. Neither branch lengths nor points in the main paper's residual plots are substituted for raw brain measurements.

The restricted `restricted_checks/Isler_vanSchaik_2012/comparison` uses these methods and correction statements as candidate-search evidence. Original measurements, per-cell types and primary-source identity remain subject to evidence review. No public measurement dataset or registry row is claimed for this source-only documentation.
