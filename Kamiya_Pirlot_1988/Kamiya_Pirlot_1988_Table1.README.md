# Kamiya & Pirlot 1988 Table 1

Source: Kamiya, T., & Pirlot, P. (1988). The brain of the Malayan bear
(*Helarctos malayanus*). *Zeitschrift für Zoologische Systematik und
Evolutionsforschung, 26*(3), 225–235.
https://doi.org/10.1111/j.1439-0469.1988.tb00312.x

The frozen source is Table 1, “Progression indices,” on printed p. 231 (PDF
p. 7) of `Kamiya-1988-The Brain of the Mal.pdf`. The snapshot preserves all
ten structure-code rows, three printed genus columns, and their source order.
The displayed table was checked against the rendered source page on
2026-11-26. The abbreviations below the table are described in
`reference_tables/Kamiya_Pirlot_1988_Table1_definitions.csv`; the printed
indices are dimensionless relative-size indices, not structure volumes.

Run `Rscript Kamiya_Pirlot_1988/Kamiya_Pirlot_1988_Table1.R` from the repo
root. It reads the frozen snapshot and writes the ten-row item CSV and the
registry-coded public TSV. The preexisting public TSV held these same Table 1
values but was mislabeled with the DOI and title of the *different* 1988
lesser-panda article. The folder's older `Kamiya_Pirlot_1980_TABLE1.*` files
are for a *Platanista* paper and are a separate item; they are not input to
this build. Human visual signoff remains pending.
