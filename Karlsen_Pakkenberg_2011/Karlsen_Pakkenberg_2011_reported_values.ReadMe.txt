Source

Snapshot
  Karlsen_Pakkenberg_2011_reported_values_snapshot.xlsx
  Faithful transcription of explicitly reported values, including the published Control temporal
  astrocyte density of 46.7 x10^6/cm3. Source page/section is retained per row.
  This snapshot requires visual sign-off against the source pages before release.

Correction
  The clean table corrects Control temporal astrocyte density 46.7 -> 23.13 x10^6/cm3.
  The R script asserts the snapshot contains exactly one matching 46.7 row before changing it.
  The author workbook gives 23.13; 46.7 is approximately 2x that value and would imply ~53% astrocytes,
  contradicting the paper's own ~29% astrocyte fraction. The snapshot intentionally remains unchanged.
  DS temporal astrocyte density 85.9 is retained and flagged as not independently verified.
