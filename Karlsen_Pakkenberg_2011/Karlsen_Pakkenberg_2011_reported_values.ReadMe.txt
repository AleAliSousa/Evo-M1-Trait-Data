Corrections   One published value is corrected in the derived table (snapshot left faithful):
              - Control temporal-cortex astrocyte density: published 46.7 -> corrected 23.13 x10^6/cm3.
                Why: 46.7 is exactly 2x the authors' own counting record (23.13); and 46.7 would make
                astrocytes ~53% of temporal glial density (88.6), contradicting the paper's OWN stated
                glial composition (astrocytes ~29% of glia). 23.13 gives ~26%, consistent with the paper.
              - DS temporal astrocyte density (85.9) is NOT changed - it could not be independently
                verified (the authors' DS records are the pre-correction version); flagged in the
                Correction_note column, use with caution.
