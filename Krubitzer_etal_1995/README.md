# Krubitzer et al. 1995 — source only

The PDF was copied from `Flatmap_SurfaceArea_Project/papers_to_do/Cortical Image References/krubitzer_etal_1995.pdf`.

This primary monotreme paper, “Organization of Somatosensory Cortex in Monotremes: In Search of the Prototypical Plan” (*Journal of Comparative Neurology* 351:261–306), contains cortical maps but no tabulated absolute field-area dataset was created here. Figure scale bars or linear extents must not be multiplied into inferred surface areas. The source remains available for a future flatmap-digitization item.
