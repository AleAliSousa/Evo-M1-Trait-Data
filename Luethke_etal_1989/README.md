# Luethke et al. 1989 — source only

The PDF was copied from `Flatmap_SurfaceArea_Project/papers_to_do/Cortical Image References/luethke_etal_1989.pdf`.

The primary paper “Connections of Primary Auditory Cortex in the New World Monkey, *Saguinus*” (*Journal of Comparative Neurology* 285:487–513) reports rough linear extents for A-I and its surrounding fringe. Those dimensions are not multiplied into an inferred cortical surface area, so no dataset item or public TSV is created.
