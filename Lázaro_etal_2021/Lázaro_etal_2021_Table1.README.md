# Lázaro et al. 2021 — Table 1

“Geographic patterns in seasonal changes of body mass, skull, and brain size of common shrews,” *Ecology and Evolution* 11:2431–2448, DOI 10.1002/ece3.7238. The exact open-access PDF is in this folder. Table 1 spans PDF page 9. The item-specific snapshot script uses the local PDF text layer to freeze 24 printed model-result rows in source order. Run the snapshot script once only; it refuses to overwrite the frozen CSV. The reader retains the source response/predictor labels, F statistic, degrees of freedom, adjusted R², source P string, and printed correlation label plus the SW column. These are regression results about geographic/climate associations, not raw skull or brain measurements. Do not merge as trait observations.

Build command from repository root: `Rscript --vanilla Lázaro_etal_2021/Lázaro_etal_2021_Table1.R`. It reads only its frozen snapshot, writes the analysis CSV and DOI-coded public TSV via `__ReadMeAddON.xlsx`, and preserves source comparison fields. Human visual signoff remains pending. No figure-derived data were extracted.
