# Miller 2017 Table 3

Source: Daniel J. Miller, *Quantitative Analysis of the Evolution and Reorganization of Microstructure in Primates* (Vanderbilt dissertation, 2017), **Table 3. Specimens included in this study**, printed p. 31 (PDF p. 36). The table lists 20 V1 cases with genus, case code, side, and Nissl/NeuN staining. The snapshot preserves the table's order and printed genus labels. Source Methods (printed p. 28) state the species sample, but do not map each *Macaca* code to one of the three macaque species; the analysis therefore leaves those rows at `Macaca sp.`.

Run `Rscript Miller__2017/Miller__2017_Table3.R`; it reads only the frozen snapshot and writes the item CSV and `__Public/comparative-data/hdl1803-13821_Table3.tsv`. Cases `11_38`, `11_31` and `11_47` can be compared with Turner and existing Kaas records by code, allowing hyphen/underscore typography changes but preserving the originals. Do not treat a left/right entry as two different animals. AI checked the snapshot against PDF p. 36 on 2026-11-24; human signoff is pending. No figure data were extracted.

Candidate published continuation: Miller & Kaas (2026), preprint DOI 10.64898/2026.04.08.716558, reports comparative V1 neuron and glia data. Exact case overlap and numerical independence remain unverified; compare against dissertation Tables 4–8 before adding those measurements.
