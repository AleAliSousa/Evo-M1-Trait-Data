# Miller et al. 2014 Table 1

Source: Miller, Balaram, Young & Kaas (2014), *Three counting methods agree on cell and neuron number in chimpanzee primary visual cortex*, Frontiers in Neuroanatomy 8:36, DOI [10.3389/fnana.2014.00036](https://doi.org/10.3389/fnana.2014.00036). Table 1, PDF p. 4, prints 18 rows with Tissue, Quantification, Parameter, Sample and Estimate. The five-column snapshot preserves this order and the printed number/percent strings. AI compared every row against the local PDF on 2026-11-25; human visual signoff remains pending.

All rows concern **one** 53-year-old female *Pan troglodytes* from Texas Biomedical Research Institute. Methods identify flattened samples as right V1 and slices as left V1. The article does not print a case code; `KAAS-PAN-11_38` is a cross-paper identity from Miller's 2017 dissertation and the existing public crosswalk. The printed `n` is a count of samples or sampling sites as reported, **not** a count of animals. The article's text gives density units as cells or neurons/mm³, and Table 1 prints volume in mm³. Percent neurons is stored on the 0–100 scale. No sums, means, or glial counts were invented.

Run `Rscript Miller_etal_2014/Miller_etal_2014_Table1.R` from the repository root. The reader uses only this frozen snapshot and writes `Miller_etal_2014_Table1.csv` and the public TSV. It puts the six measurement classes into separate sparse numeric columns, retaining the printed estimate and method on every row. The definition file records units and row role.

**Overlap:** Miller 2017 dissertation Chapter 2 Table 1 repeats all 18 rows at printed precision. Collins et al. 2016 Table 1 has the same chimpanzee but publishes different/rounded V1 estimates and broader cortical regions; it is not a second animal. Miller 2014 supplies the currently unbuilt **method-specific** V1 counts, percentages, volumes, and densities. Keep method and hemisphere distinctions in analyses; do not pool these rows as independent specimens. Source relationships are recorded in `_keys/source_relationships.csv`.
