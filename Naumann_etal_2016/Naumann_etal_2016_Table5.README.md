# Naumann et al. 2016 — Table 5

Same article, PDF page 19 (printed p. 801). “Modifiable Areal Unit Analysis” prints three species and two scales, with slash-separated numbers of regions in **hexagonal / rectangular / no periodicity** classes. The snapshot retains the three printed rows and both slash triples. The analysis CSV/TSV has 18 species–scale–class rows, with the printed class order preserved.
