# Qi et al. 2023 deposited macaque section areas

Source: Qi et al. (2023), DOI [10.1073/pnas.2222076120](https://doi.org/10.1073/pnas.2222076120), public Vanderbilt [deposited workbook](https://ir.vanderbilt.edu/bitstreams/64cd0a44-c78f-48d2-b131-d2160daa6f3d/download) `CuN_Area_Measure_MM_RawData.xlsx`. The original digital-native file is copied here verbatim. No transcribed snapshot is needed; the source is already tabulated. The workbook has 74 worksheets for the same 37 macaque case codes in SI Table S1. AI checked panel structure and spot-checked source cells on 2026-11-25; the registry records “Not applicable: tabulated and digital already” for snapshot visual signoff.

Run `Rscript Qi_etal_2023/Qi_etal_2023_RawAreasMM.R` from the repository root. It reads the workbook directly and writes 5,356 section × panel × worksheet-version area records to the CSV and public TSV. Each record retains the case, original worksheet and cell address, panel order, section marker, available distance from obex, and an interpolation flag. First and second area panels are cuneate left/right; third and fourth, when present, are pars rotunda left/right. No rater averaging, smoothing or section interpolation is done by the reader. The source workbook itself contains nine area cells marked `Skipped`/`Avg from adjacent`; those values remain in the output and are flagged as source interpolations.

`hemisphere=unresolved` marks a printed side label that conflicts with panel order (six records in `93-18_let`); inspect that worksheet before using those records for side-specific estimates. A blank workbook group means the worksheet title did not expose the group in the standard title pattern. The original worksheet title and source cell remain available. Multiple `hxq`, `let`, or other worksheet variants are repeated measurements of one animal, not independent specimens. The published SI Table S1 supplies case-level signed **mean-area differences**; naive averaging of all deposited source area cells is not guaranteed to recreate the SI percentage because source sheets include different raters, selected sections and quality-control decisions. No derived case mean or ratio is written here.
