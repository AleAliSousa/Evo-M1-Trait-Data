# Qi et al. 2023 deposited other-primate section areas

Source: Qi et al. (2023), DOI [10.1073/pnas.2222076120](https://doi.org/10.1073/pnas.2222076120), public Vanderbilt [deposited workbook](https://ir.vanderbilt.edu/bitstreams/fd320af5-6f85-421f-b449-7adaa00be33c/download) `CuN_Area_Measure_SQM_RawData.xlsx`. The original digital-native file is copied here verbatim. No transcribed snapshot is needed; the source is already tabulated. Its 208 worksheets cover the same 85 case codes as SI Table S2, with `hxq`, `let`, `ks`, and `Redo` versions in some cases. AI checked panel structure and spot-checked source cells on 2026-11-25; the registry records “Not applicable: tabulated and digital already” for snapshot visual signoff.

Run `Rscript Qi_etal_2023/Qi_etal_2023_RawAreasSQM.R` from the repository root. It reads only this workbook and writes 12,329 section × side-panel × worksheet-version area records to the CSV and public TSV. Each record retains exact worksheet and source cell, case, panel order, section marker, available distance from obex and an interpolation flag. First and second Area panels are cuneate left/right. The reader retains 324 deposited cells marked `Skipped`/`Avg from adjacent` as source interpolations; it does not generate new interpolated values, averages or ratios.

`hemisphere=unresolved` marks 222 records in five worksheets whose printed side labels conflict with panel order; source review is needed before using them for side-specific summaries. The workbook title group (`SM`, `OM`, `Gal`, etc.) is retained when parsed; it is not a species determination. SI Table S2 gives the published taxon label for each case. Multiple worksheet versions are the same animal measured or revised again, not additional specimens. The SI's signed **mean-area differences** are the published case-level result; naive averaging of deposited sheets is not guaranteed to reproduce it because of section matching, rater choice and quality-control decisions. No derived case mean or ratio is written here.
