# Schenker 2007 Chapter III Table 3.1a

Source: Natalie M. Schenker, *Comparative Analysis of Broca's Area in Hominoids* (UC San Diego dissertation, 2007), Table 3.1a, “Uncorrected volumetric estimates,” printed p. 105 / local PDF p. 121. The 14-row snapshot follows the printed specimen and column order. AI compared it directly with the rendered source page on 2026-11-25; human visual signoff remains pending.

Run `Rscript Schenker__2007/Schenker__2007_Table3_1a.R` from the repository root. The item reads its frozen snapshot and writes 54 measured specimen × hemisphere × BA44/45 rows to CSV and public TSV. It excludes only the two source dashes for `CS025`'s right BA measurements. Brain weight remains grams. Source hemisphere volumes in cm³ are multiplied by 1,000; source BA volumes are already mm³. `1548` and `A375` have BA measurements but no printed hemisphere volume. The source's `Adult`, `Juvenile`, unknown sex and `NA` weight are retained without inferred values.

These are **uncorrected** histological volumes. Table 3.1b prints corrected volumes and case correction factors, but its BA44/45 correction is internally inconsistent and that table is reference-only. Use these dissertation values only for a specimen/endpoint not available from a peer-reviewed publication; replace them with the published values if a matching journal table is found. Printed hemisphere volume repeats across BA44/45 rows; one case is one animal. Chapter II's published minicolumn results and Schenker et al. 2010's `C`-coded chimpanzees are different measurements/cohorts and do not currently replace these named-case volumes.
