# Schenker 2007 Chapter III Table 3.1b — reference only

**DO NOT USE this table as a trait dataset.** The dissertation's Table 3.1b, “Corrected volumetric estimates” (printed p. 105 / local PDF p. 121), is retained here only as the frozen [source transcription](Schenker__2007_Table3_1b_snapshot.csv). The cell-by-cell inconsistency check is filed in the restricted repo at `restricted_checks/Schenker__2007/comparison/Schenker__2007_Table3_1b_internal_check.csv`. No analysis CSV, public TSV, item reader, or trait definitions are maintained for Table 3.1b. The `__ReadMeAddON.xlsx` row is marked `REFERENCE ONLY` and `DO NOT USE`.

The reproducible check, run with `Rscript restricted_checks/Schenker__2007/comparison/Schenker__2007_Table3_1b_internal_check.R` from the restricted repo root, compares Table 3.1b with Table 3.1a and Table 3.2. The 54 corrected BA44/45 cells all imply a multiplier of about 2.0788, while the dissertation prints specimen-specific correction factors from 1.31 to 2.74. **50 of 54** BA cells disagree with the printed factor beyond 0.015; the four `SN207/84` cells agree. Corrected hemisphere volumes and density ratios do follow the specimen factors, so the discrepancy is localized to the corrected BA volume columns. This is strong evidence of a source table or spreadsheet formula error, but it is not an author-confirmed erratum. No substitute corrected volumes are inferred here.

The cross-publication correction-factor check, filed in the restricted repo at `restricted_checks/_cross_table/Schenker_2007_vs_deSousa_2008_2010/`, compares 12 shared specimens with de Sousa 2008 Table 5.1 and de Sousa et al. 2010 Table 1. Nine printed factors differ from Schenker's, consistent with differing correction-factor provenance, but those differences do not account for Table 3.1b's nearly uniform BA multiplier. The check also flags an unresolved bonobo difference in de Sousa 2008 Table 5.6 species means.

The standing source rule is **peer-reviewed publication first for the same specimens and endpoint**. [Schenker et al. 2008](https://doi.org/10.1002/cne.21792) publishes Chapter II minicolumn results, and [Schenker et al. 2010](https://doi.org/10.1093/cercor/bhp138) publishes BA volumes and neuron estimates for a different `C`-coded chimpanzee cohort. Neither replaces Chapter III's named-case measurements on the current evidence.
