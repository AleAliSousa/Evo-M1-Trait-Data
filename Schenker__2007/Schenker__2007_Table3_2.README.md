# Schenker 2007 Chapter III Table 3.2

Source: Natalie M. Schenker, *Comparative Analysis of Broca's Area in Hominoids* (UC San Diego dissertation, 2007), Table 3.2, “Neuronal number and density estimates,” printed p. 106 / local PDF p. 122. The snapshot preserves all 14 roster rows and the source's count, uncorrected-density and corrected-density blocks. AI compared it with the rendered source page on 2026-11-25; human visual signoff remains pending.

Run `Rscript Schenker__2007/Schenker__2007_Table3_2.R` from the repository root. It outputs 44 measurements: 11 specimens × two hemispheres × BA44/45. `CS025`, `1548`, and `A375` have only printed dashes in this table and therefore no measurement rows. Printed counts in millions become absolute neuron counts (×1,000,000); densities in thousands/mm³ become neurons/mm³ (×1,000). Both density bases remain distinct. The Methods state that the optical fractionator estimated counts, uncorrected density uses uncorrected volume, and corrected density uses shrinkage-corrected volume.

The cross-table check, filed in the restricted repo at `restricted_checks/Schenker__2007/comparison/Schenker__2007_Table3_1b_internal_check.csv`, finds that the ratio of uncorrected to corrected density follows the specimen correction factor within 0.0043 for every available case, despite Table 3.1b's corrected **BA volume** error. Table 3.1b is now reference-only; do not derive neuron counts from its suspect corrected BA volumes. Use these dissertation counts and densities only while the same named-specimen endpoints are unavailable in a peer-reviewed publication. Counts and densities refer to the same specimen/hemisphere/area, not independent animals.
