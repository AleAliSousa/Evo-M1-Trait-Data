## What it is
Per-animal age (days), weight (g), sex. Specimen-level but the cell-count results (Tables 3-5) are published only as group means, so these cannot be linked to individual counts. METHOD WARNING: the paper states it used the **isotropic fractionator** (nuclei counted in a Neubauer chamber, NeuN fraction by flow cytometry); it is NOT stereological/histological sectioning counting. Measure codes follow the repo isotropic-fractionator set (C.n, N.n, O.n, p.C.N, Mass.g).
