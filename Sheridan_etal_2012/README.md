## Built items and remaining evidence

This is primary human MRI/EEG evidence from the Bucharest Early Intervention
Project: never-institutionalized children, institutional-care children, and a
foster-care intervention group. Main Tables 1-3 report model coefficients
(with SE), not per-species brain volumes. Figures 1-2 plot cohort means for
total cortical gray and white matter volume, with bars identified as ±1 SEM.
Built items: Table 1 (10 coefficient/SE cells), Table 2 (15 cells), Figure 1
(three approximate cortical grey-matter means with ±1 SEM), and Figure 2
(three approximate cortical white-matter means with ±1 SEM). See each item
README for the reader, visual check, and caveats. The existing candidate inventory is
`_other_sources_metab_correlates_candidates/literature_candidates_all_studies.csv`
(Sheridan 2012 row).

The journal supplement, including average structural volumes in Table S2 and
subcortical analyses in Table S3, could not be retrieved from the available
journal/PMC links. Obtain and inspect it for possible additional items. Compare
participants and measurements with McLaughlin et al. 2014 and Sheridan et al.
2022 before using any values. Do not interpret clinical/intervention groups as
an independent healthy species baseline.
