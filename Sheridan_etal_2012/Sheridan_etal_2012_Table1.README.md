# Sheridan et al. 2012 Table 1

Source: `Sheridan-2012-Variation in neural development.pdf`, printed Table 1,
PDF page 3. The snapshot preserves both cortical tissue blocks, printed group
rows, model columns, coefficient cells, parentheses, and dagger markers. Run
`Rscript Sheridan_etal_2012/Sheridan_etal_2012_Table1.R` from the repo root.
It writes 10 coefficient cells to the analysis CSV. Parentheses are standard
errors of regression coefficients, not cohort SEM. NIG is the reference group.
The coefficient unit is not explicit in the table, so none is assigned. The
clinical arms remain distinct and are not species baseline measurements.

The PDF and snapshot were checked against each other on 2026-11-26; no human
visual signoff is claimed. Main-registry registration and public TSV remain
pending; see the proposed registry-row workbook of the same item name.
