# Soto et al. 2022 source disposition

Soto, C., Gázquez, J. M. M., & Llorente, M. (2022). Hand preferences in coordinated bimanual tasks in non-human primates: A systematic review and meta-analysis. *Neuroscience & Biobehavioral Reviews*, 141, 104822. [DOI](https://doi.org/10.1016/j.neubiorev.2022.104822).

The exact review PDF is held in this folder. PDF pages 5–6 contain Table 1, an index of 64 included studies with species, sample sizes and task types; page 6 contains Table 2, a secondary species-by-task sample summary. These do not print the primary individual HI/MHI observations sought for Püschel provenance. No primary dataset item was created from the review to avoid treating pooled or indexed values as new observations. Use the two tables as a locator when acquiring a specific primary study. The Püschel source queue records this disposition as of 2026-11-23.
