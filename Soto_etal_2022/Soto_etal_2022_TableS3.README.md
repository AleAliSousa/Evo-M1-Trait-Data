# Soto et al. 2022 — Table S3

Soto, C., Gázquez, J. M. M., & Llorente, M. (2022), “Hand preferences in coordinated bimanual tasks in non-human primates: A systematic review and meta-analysis,” *Neuroscience & Biobehavioral Reviews* 141:104822, DOI 10.1016/j.neubiorev.2022.104822. The exact publisher PDF and supplementary DOCX `1-s2.0-S0149763422003116-mmc1.docx` are in this folder. The source is Table S3: “Moderator variable analysis for the handedness index in NHP performing the tube task. Bold species indicate significant effect.”

The frozen XLSX was extracted directly from the publisher DOCX table on 2026-11-24, preserving source row and column order, decimal commas, the printed caption, bold/italic emphasis and the source’s exact labels. Run `python Soto_etal_2022/Soto_etal_2022_TableS3_snapshot.py` **only when first creating the snapshot**; it refuses to replace an existing frozen copy. Python was used for snapshot creation because the installed R `openxlsx` writer produced an invalid drawing relationship; the item reader remains R. Human visual signoff of the extracted table is pending.

Run from repository root: `Rscript --vanilla Soto_etal_2022/Soto_etal_2022_TableS3.R`. The script reads only the frozen XLSX and writes `Soto_etal_2022_TableS3.csv` plus a DOI-coded TSV in `__Public/comparative-data/` using the `Item encoded` value in `__ReadMeAddON.xlsx`. It retains all 21 species rows for the tube task, parses point estimates and 95% confidence bounds as dimensionless indices, and preserves printed p-value strings with numeric threshold and operator separated. `number_of_studies` counts source studies, **not animals**. Source taxon labels, including subspecies, are unchanged. Definitions are in `reference_tables/Soto_etal_2022_TableS3_definitions.csv`.

The source prints −1.040 for *Cercocebus torquatus torquatus* and confidence bounds outside the signed index range [−1, 1]. These are retained and flagged. The values are **secondary species moderator estimates**. Tables S3–S4 describe signed handedness direction (MHI); S5–S6 describe absolute handedness strength (MABSHI). Their underlying study samples may overlap Caspar et al. 2022 and Püschel et al. 2026; do not pool these rows as independent primary data or average across task types. No figure-derived dataset was created, so no figure replot applies.
