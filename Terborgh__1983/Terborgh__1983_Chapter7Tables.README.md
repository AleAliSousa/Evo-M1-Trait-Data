# Terborgh 1983 — Chapter 7 Tables 7.1–7.5

Source: Terborgh, *Five New World Primates* (1983), institutional [VLeBooks reader](https://r3.vlebooks.com/Reader?ean=9781400857166), ISBN 9781400857166. The owner supplied institutional access. Printed pages 131, 137, 142, 146, and 151 were inspected in the live book reader on 2026-11-26. The source is a book view, not a frozen local PDF.

`Terborgh__1983_Chapter7Tables_snapshot.py` records a manual transcription from the visible tables in source order. Run `python3 Terborgh__1983/Terborgh__1983_Chapter7Tables_snapshot.py` to regenerate its 150-row long snapshot, then `Rscript --vanilla Terborgh__1983/Terborgh__1983_Chapter7Tables.R` to regenerate the item CSV and public TSV. The reader uses no merge, smoothing, or inferred values. It parses only plain printed numbers; inequalities, parenthesized source ratios, and unclear footnote glyphs stay in `value_as_printed` with an empty numeric value.

Table 7.1 has five species summaries; Table 7.2 has travel samples plus four printed mean rows; Table 7.3 has spatial-use rows; Table 7.4 compares fruit periods; Table 7.5 contributes only the four New World rows from Terborgh's study. Its 16 Old World comparison rows cite Clutton-Brock and Harvey (1977a) and are omitted to prevent a secondhand build. Table 7.5 group size, density, and range repeat some Table 7.1 results. Table 7.2 printed means repeat underlying sample summaries and must not be pooled with them as independent observations. Table 7.5 diet percentages are percentages of observation time.

The two Saguinus cumulative Table 7.3 values carry glyphs that could not be separated reliably in the reader; the visible strings `30,21` and `30,24` are preserved and have no parsed numeric value. Table 7.1 parenthesized densities are earlier census estimates, not standard deviations. Table 7.4 parentheses are ratios to the maximum fruit period, not error bars. No figure-derived data were extracted, so no replot is applicable. A second person has not visually signed off on the transcription.
