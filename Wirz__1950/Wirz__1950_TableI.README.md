# Wirz (1950), Table I

Source: Katharina Wirz, *Studien über die Cerebralisation: Zur quantitativen Bestimmung der Rangordnung bei Säugetieren*, Acta Anatomica 9(1–2):134–196, DOI 10.1159/000140431. This is the same author who later published as Katharina Mangold-Wirz. The source PDF is in this folder.

The `_source.tsv` transcribes the group-level relation exponents (`r`) on pp. 145–147. The local CSV and public TSV are generated by `MangoldWirz__1966/build_tables.py`. Each row is a systematic group with its included taxa as printed. These are allometric model parameters, not species-level observations or brain weights. They must not enter species mass or regional volume pooling. The 1966 paper revisits the earlier cerebralisation framework, so analyses of both tables should account for author and conceptual dependence.
