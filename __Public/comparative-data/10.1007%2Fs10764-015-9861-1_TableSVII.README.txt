Table SVII. Distribution of the vocalizations of Eulemur flavifrons in the clusters identified using the affinity
propagation algorithm.

Columns indicate the result of the a priori classification (AC = Alarm Call, CH = Chatter, H = Hoot, GH = Grunted
Hoot, GR = Grunt, GT = Grunt-Tonal Call, LG = Long Grunt, LGTC = Long Grunt-Tonal Call, TO = Tonal Call),
while rows show cluster membership and composition. The number of vocalizations in a cluster (TOT), the number of
vocalizations corresponding to an a priori vocal type (Input), and the number of exemplars chosen from that vocal type
during the cluster analysis (Exemplars) are also reported.
