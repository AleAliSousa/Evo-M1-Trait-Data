## Columns (all files)

- `Species`: accepted name (house species key); blank for groups such as 'New World monkeys'. `taxon_as_printed` and `taxon_in_methods` keep the printed names; `species_as_published` is the name the key resolves.
- `trait` (code) and `feature` (plain words); `layer`, `marker` (CO = cytochrome oxidase, NPNF = SMI-32 neurofilament, MAP 2, Cat-301, calbindin).
- `state`: present, absent, reduced, uncertain, or a printed category (e.g. 'label-sparse band', 'layer 4B'); blank for size rows, which use `value_low`-`value_high` in `unit` (um).
- `n_individuals`: individuals examined for that stain in that taxon (Methods), where printed.
- `state_basis`: 'stated (legend / Results / Discussion)', or, for tree figures, 'inferred ...' / 'uncertain ...' / 'no data published ...'. Inferred rows are the authors' reconstruction, not observations.
- `printed_wording` (short quote), `source_locator` (figure or section, page, panel), `observation_level`, `data_role`, `note`, `source` (item name).

## Caveats

- Group statements ('apes and humans', 'monkeys', 'none of the other species') were expanded to each taxon examined; those rows share one printed sentence.
- Macaques are pooled in the paper (several Macaca species), so they appear as Macaca sp.
- Fig 11 prints, per genus, which kinds of data were published (letters a-e) and annotation boxes; per-genus states are given only where the letter is printed and are inferred from the reconstruction.
- Staining-strength rows describe antibody sensitivity under the protocol, not anatomy.
