Püschel, Hurwitz & Venditti (2026) PLoS Biol 24(4): e3003771, S1 Data ("Dataset analyzed in the present study"). Built 2026-11-03 from the journal CSV, values as printed.

One row = one tube-task hand-preference study sample x species: 71 rows, 41 anthropoid species (incl. Homo sapiens; orang-utans as Pongo sp.), 2,025 individuals.
- mean_mhi: mean handedness index (direction; -1 left to +1 right).
- mean_mabshi: mean absolute handedness index (strength; 0-1).
- Each with SD, SE and sample_size (n).
Species-level covariates repeat on every row of a species, each with the reference the authors printed: body mass (kg; body_mass_g added), ECV (cm3; ecv_mm3 added), tool use, substrate, % fruit, % fruit + animal, social system, IMI, competition level, extractive foraging, social learning and body-mass dimorphism.

SECONDARY data: the authors compiled every value from the cited work.
- 26 rows are Caspar et al. 2022's own samples, so do not pool with the Caspar handedness data.
- imputed_* = Yes marks the authors' model estimates, not data.
- Table checks found 4 inconsistencies.
- Rows 59 and 60 (Sapajus apella) print identical values; they may be one sample counted twice.
