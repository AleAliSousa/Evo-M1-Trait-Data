# de Rooij et al. 2016 — Table 3

“Prenatal famine exposure has sex-specific effects on brain size,” *Brain* 139:2136–2142, DOI 10.1093/brain/aww132. The exact PDF is in this folder; Table 3 is on PDF page 5 (printed p. 2140). The frozen three-row source-order snapshot was manually checked against the rendered PDF on 2026-11-24. It preserves the three famine-exposure columns, total statistic, sample size, and P value. The source footnote says arithmetic means (SD), except WMH geometric mean (geometric SD). The group-specific dispersion is not supplied.

Run from repository root: `Rscript --vanilla deRooij_etal_2016/deRooij_etal_2016_Table3.R`. The reader uses only the frozen snapshot, makes 12 group-by-measure rows, and writes analysis CSV plus DOI-coded public TSV via `__ReadMeAddON.xlsx`. The mean diffusion label reports values in ×10³ mm²/s and is retained in that printed scale. The printed WMH values are 2969, 2796, 2552, and 2757 ml, which appear implausibly large for white matter hyperintensity volume. They remain verbatim, with a row flag; do not use WMH values in a quantitative merge until the source magnitude is clarified. P compares exposed participants to combined unexposed groups and is repeated only as context. These are human exposure-group summaries, not comparative species measurements. Human visual signoff remains pending. No figure-derived data were extracted.
