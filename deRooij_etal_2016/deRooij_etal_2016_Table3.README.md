# de Rooij et al. 2016 — Table 3

“Prenatal famine exposure has sex-specific effects on brain size,” *Brain* 139:2136–2142, DOI 10.1093/brain/aww132. The exact PDF is in this folder; Table 3 is on PDF page 5 (printed p. 2140). The frozen source-order snapshot was checked against the rendered PDF. The layout edit restored the printed title, `Exposure to famine` spanning heading, and source footnotes, while removing analysis metadata columns. The R reader derives units and summary types from the printed labels and footnote. The group-specific dispersion is not supplied.

Run from repository root: `Rscript --vanilla deRooij_etal_2016/deRooij_etal_2016_Table3.R`. The reader uses only the frozen snapshot, makes 12 group-by-measure rows, and writes analysis CSV plus DOI-coded public TSV via `__ReadMe.xlsx`. The analysis measurements match the pre-edit CSV; only physical source-row identifiers change. The mean diffusion label reports values in ×10³ mm²/s and is retained in that printed scale. The printed WMH values are 2969, 2796, 2552, and 2757 ml, which appear implausibly large for white matter hyperintensity volume. A rendered PDF check confirms that those digits are printed, so they remain verbatim with a row flag; do not use WMH values in a quantitative merge until the source magnitude is clarified. P compares exposed participants to combined unexposed groups and is repeated only as context. These are human exposure-group summaries, not comparative species measurements. No figure-derived data were extracted.
