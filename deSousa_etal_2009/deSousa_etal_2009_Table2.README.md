# deSousa_etal_2009 — Table 2 (RMA regressions of V1/V2/VP GLI)

## What this item is
de Sousa, Sherwood, Schleicher, Amunts, MacLeod, Hof & Zilles (2009) measure grey level index
(GLI) in areas V1, V2 and VP of hominoids. **Table 2** ("RMA regressions of V1, V2, and VP GLI
values on brain and visual system variables") reports reduced-major-axis regression statistics
(slope, intercept with 95% CIs, R2, p) of each area's mean GLI against neocortex volume, V1
volume, LGN volume, and optic-nerve cross-sectional area — 8 regressions total, transcribed
exactly as printed (`deSousa_etal_2009_Table2_snapshot.csv`).

## Not built here: the raw per-species GLI values
The regression's *inputs* (mean cortical GLI per species for V1/V2/VP) are plotted in Fig. 6
(species means, bar chart with 95% CI for chimpanzee and human) and broken down by layer in
Fig. 7 — neither is a printed table, and no supplementary GLI table was found in this PDF. Only
the registry line the project owner added (`Item name = deSousa_etal_2009_Table2`, matching this
printed table) is built in this pass. Digitizing Fig. 6/7 would need its own registry line and is
left as a future item if raw per-species V1/V2/VP GLI values are wanted for `__merging_GLI`.
